Welcome to CCCSMP

Welcome to CCCSMP, a Minecraft survival server where you can build, explore, fight and create your own story.

Make alliances, protect your base and survive against other players.

Server Information

Version: 1.26.3

Server IP: cccsmp.apect.host

Port: 19132

How to Join CCCSMP

Java Edition

  1. Open Minecraft Java Edition.
  2. Make sure you are using version 1.26.3.
  3. Click Multiplayer.
  4. Click Add Server.
  5. Enter CCCSMP as the server name.
  6. Enter the server address: cccsmp.apect.host
  7. Click Done, select the server and click Join Server.

Bedrock Edition

  1. Open Minecraft Bedrock Edition.
  2. Go to the Servers tab.
  3. Scroll down and select Add Server.
  4. Enter CCCSMP as the server name.
  5. Enter cccsmp.apect.host as the address.
  6. Enter port 19132.
  7. Save and connect.

Having trouble? Check your version and server address. Java and Bedrock may require different connection settings.

CCCSMP Rules

1. Gameplay

  • Griefing, stealing, raiding and PvP are allowed.
  • Trapping and betrayal are allowed.
  • Alliances and rivalries are encouraged.
  • No refunds for lost or destroyed items.

2. Cheating

  • No X-ray or hacked clients.
  • No KillAura, Reach, AimAssist or autoclickers.
  • No macros or unfair exploits.
  • No duping unless staff explicitly permits it.
  • No server-crashing or lag exploits.

3. Mods

  • Performance mods are allowed.
  • Sodium, Lithium, FerriteCore and shaders are allowed.
  • Minimaps are allowed.
  • Fullbright requires staff permission.
  • X-ray resource packs are prohibited.

4. Chat

  • No doxxing or sharing personal information.
  • No real-life threats or targeted harassment.
  • No excessive spam or staff impersonation.
  • Keep arguments in-game.

5. Server Integrity

  • No intentional server crashing.
  • No lag machines designed to overload the server.
  • No plugin exploits or ban evasion.
  • Do not interfere with server administration.

6. Staff Enforcement

Staff may investigate suspected cheating, request removal of prohibited mods, issue warnings, temporary mutes or bans, and permanent bans for serious offences. Punishments depend on evidence and severity.

Remember

Griefing is part of the game. Cheating is not.

Play fair. Survive. Don't get caught lacking.
